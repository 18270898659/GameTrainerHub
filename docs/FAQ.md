# 常见问题解答 | FAQ

### 1. 首次启动提示缺少 WebView2 Runtime 怎么办？
Windows 10 早期版本可能未预装 Microsoft Edge WebView2 Runtime。在安装引导弹窗中选择「是」，或手动访问微软官方页面下载安装 Evergreen Bootstrapper 后即可正常运行。

### 2. 杀毒软件误报修改器或主程序怎么办？
游戏修改器由于涉及内存读写特性，常被 Windows Defender 或第三方杀毒软件误报。GameTrainerHub 本身不包含任何恶意行为，并在启动前提供文件路径与 SHA-256 校验值供核对；如确认来源可信，可将下载目录添加至安全软件白名单。

### 3. 覆盖安装时提示“程序正在运行”但无法自动退出？
若客户端正在执行系统级阻塞操作或托盘未响应，安装程序会在等待 6 秒超时后弹出重试/取消提示。此时可先手动右键系统托盘图标退出客户端（或在任务管理器结束 `GameTrainerHub.exe`），再点击「重试」继续安装。

### 4. 全局快捷键注册失败或提示冲突？
Windows 全局快捷键不允许与其他正在运行的软件（如输入法、录屏工具、游戏内覆盖层）重复占用同一组合键。请在客户端「设置 -> 全局快捷键」中更换其他组合键后重新点击「应用」。

### 5. 用户数据存储在哪里？重装会丢失吗？
配置、SQLite 数据库（`trainers.db`）和默认下载目录均保存在 `%APPDATA%\GameTrainerHub`，与程序安装目录隔离，正常覆盖升级或卸载均不会删除您的个人数据。
