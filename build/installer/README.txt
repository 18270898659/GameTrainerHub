Game Trainer Hub - 便携版使用说明 (Portable Edition Readme)
========================================================================

版本：1.0.0 (x64)
发布日期：2026-11-23

【快速启动】
双击运行 `GameTrainerHub.exe` 即可启动客户端。
无需管理员安装权限，无需运行安装向导。

【运行依赖】
1. 操作系统：Windows 10 / 11 (64位)
2. 运行时依赖：Microsoft Edge WebView2 Runtime。
   Windows 10 较新版本和 Windows 11 已内置此组件。
   如果运行时提示缺少 WebView2，请前往微软官方网站下载安装：
   https://developer.microsoft.com/en-us/microsoft-edge/webview2/

【用户数据与存储】
- 为保证多用户环境与安全权限兼容，客户端配置文件、下载记录与缓存数据库统一存储于：
  %APPDATA%\GameTrainerHub\
- 如需重置或备份数据，直接操作上述目录即可。
